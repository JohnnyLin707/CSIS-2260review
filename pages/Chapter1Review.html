Processor (CPU): it controls the computer and does the data processing.

处理器（CPU）：控制计算机并完成数据处理。

Main memory: it stores data and programs while they are being used. It is volatile (RAM).

主存储器：存放正在使用的数据和程序，是易失性的（RAM）。

I/O modules: they move data between the computer and the outside world, for example disks, keyboard and screen.

I/O 模块：在计算机与外部世界之间传送数据，例如硬盘、键盘和显示器。

System bus: it connects the processor, main memory and I/O modules and lets them communicate.

系统总线：把处理器、主存储器和 I/O 模块连接起来，使它们能够相互通信。

Source: “Ch01v2a.pdf” — lecture slides

Primary memory (main memory, RAM) is fast, small and expensive per bit; the CPU can use it directly.

主存储器（RAM）速度快、容量小、每比特成本高，CPU 可以直接使用。

Primary memory is volatile: the data is lost when the power is turned off.

主存储器是易失性的：断电后数据会丢失。

Secondary memory (hard disk, SSD) is slow, very large and cheap per bit; it keeps data permanently (nonvolatile).

二级存储器（硬盘、固态硬盘）速度慢、容量大、每比特便宜，并且能永久保存数据（非易失）。

Data in secondary memory cannot be processed directly by the CPU; it must first be loaded into main memory.

外存中的数据不能被 CPU 直接处理，必须先装入主存储器。

Source: “Ch01v2a.pdf” — lecture slides

Human-readable devices: used to talk with the user, for example screen, printer, keyboard, mouse.

人可读设备：用于与用户交互，例如显示器、打印机、键盘、鼠标。

Machine-readable devices: used to talk with equipment, for example disks, tapes, sensors and actuators.

机可读设备：用于与设备本身交互，例如磁盘、磁带、传感器和执行器。

Communication devices: used to talk with remote devices, for example network card and modem.

通信设备：用于与远端设备通信，例如网卡和调制解调器。

We can also group them by direction: input, output, storage and communication devices.

也可以按方向分类：输入设备、输出设备、存储设备和通信设备。

Source: “Ch01v2a.pdf” — lecture slides

a. GPU (graphics processing unit): many small cores; it does the same calculation on many data items at the same time.

a. GPU（图形处理器）：内含许多小核心，可以同时对大量数据做同一种运算。

The GPU was made for graphics and images, but it is now also used for general calculation.

GPU 原本用于图形图像，现在也用来做通用计算。

b. DSP (digital signal processor): a special processor that processes signals such as sound, video and radio in real time.

b. DSP（数字信号处理器）：专门实时处理声音、视频、无线电等信号的处理器。

A DSP uses special hardware and instructions, for example fast multiply-and-add.

DSP 使用专门的硬件与指令，例如快速的乘加运算。

c. Cache: a small and very fast memory inside or next to the CPU.

c. Cache（高速缓存）：位于 CPU 内部或旁边的一小块高速存储器。

It keeps copies of the data and instructions that were used recently, so the CPU does not have to go to main memory each time.

它保存最近用过的数据和指令的副本，这样 CPU 不必每次都去访问主存储器。

Source: “Ch01v2a.pdf” — lecture slides

SoC means system on a chip: all or most of the components of the computer are put on one single chip.

SoC 即片上系统：计算机的全部或大部分部件都被放在同一块芯片上。

These components are the CPUs and caches, and also the GPU, DSP, memory controller and I/O devices such as codecs and radios.

这些部件包括 CPU 与缓存，还包括 GPU、DSP、内存控制器以及编解码器、无线模块等 I/O 设备。

One chip is smaller, cheaper, uses less power and is faster because the components are close together.

单芯片体积更小、成本更低、更省电，并且因为各部件靠得很近而更快。

Source: “Ch01v2a.pdf” — lecture slides

I/O devices are much slower than the processor.

I/O 设备的速度远慢于处理器。

Without interrupts the processor must wait and test (poll) the device status again and again, and this time is wasted.

没有中断时，处理器必须不停地等待并反复查询设备状态，这段时间就被浪费了。

With interrupts the device sends a signal when it is ready, and the processor can do other useful work before that.

有了中断，设备在准备好时发出信号，处理器在这之前可以做其他有用的工作。

Source: “Ch01v2a.pdf” — lecture slides

Program: caused by the execution of an instruction, for example arithmetic overflow, division by zero, illegal instruction, or a memory reference outside the allowed space.

程序中断：由指令执行引起，例如算术溢出、除以零、非法指令或越界访问存储器。

Timer: caused by a timer inside the processor; it lets the operating system do certain work regularly.

定时器中断：由处理器内部的定时器产生，使操作系统能够定期执行某些工作。

I/O: caused by an I/O controller; it signals normal completion of an operation or an error condition.

I/O 中断：由 I/O 控制器产生，表示操作正常完成或出现错误。

Hardware failure: caused by a failure such as power failure or a memory parity error.

硬件故障中断：由电源故障、存储器奇偶校验错误等故障引起。

Source: “Ch01v2a.pdf” — lecture slides

The processor can start an I/O operation and then continue with another program.

处理器可以启动一次 I/O 操作，然后继续执行另一个程序。

The processor and the I/O device work at the same time instead of waiting for each other.

处理器与 I/O 设备同时工作，而不是互相等待。

The processor is interrupted only when the device really needs service, so little time is wasted.

只有在设备真正需要处理时才会中断处理器，因此浪费的时间很少。

Source: “Ch01v2a.pdf” — lecture slides

Every interrupt has a priority.

每个中断都有自己的优先级。

If the new interrupt has a lower or the same priority, it stays pending; the current handler finishes first.

如果新中断优先级更低或相同，它就保持等待，先处理完当前的中断服务程序。

If the new interrupt has a higher priority, it is allowed to interrupt the current handler (a nested interrupt); it runs first.

如果新中断优先级更高，它可以打断当前的中断服务程序（嵌套中断），先执行自己。

The processor then saves the state, runs the higher-priority handler, and later goes back to the first handler.

处理器先保存现场，执行高优先级的服务程序，之后再回到第一个服务程序。

Source: “Ch01v2a.pdf” — lecture slides

No single memory is fast, large and cheap at the same time, so we combine several levels.

没有哪一种存储器能同时做到又快、又大、又便宜，所以要把几种存储器组合起来。

Going down the hierarchy: cost per bit goes down, capacity goes up, access time goes up, and the processor accesses that level less often.

沿层次向下：每比特成本降低、容量增大、访问时间变长、处理器访问该层的频率降低。

The small fast levels near the CPU are expensive per bit, so they can only be small.

靠近 CPU 的高速层每比特都很贵，所以只能做得很小。

The large cheap levels are slow, so we keep there only the data that is not needed often.

廉价的大容量层速度慢，所以只把不常用的数据放在那里。

Source: “Ch01v2a.pdf” — lecture slides

Memory references by the processor tend to cluster into groups.

处理器的存储器访问倾向于成簇（集中）出现。

Temporal locality: an item that was just used will probably be used again soon (because of loops, subroutines, counters).

时间局部性：刚被访问过的项很可能很快再次被访问（因为循环、子程序、计数器）。

Spatial locality: items next to the item just used will probably be used soon (because instructions are executed in order and data is stored in arrays).

空间局部性：与被访问项相邻的项很可能很快被访问（因为指令顺序执行、数据常以数组存放）。

It is important because with locality most accesses can be served by the small fast memory level, so the computer is fast and still cheap.

它很重要：有了局部性，大多数访问都能由小而快的高层存储器满足，计算机又快又便宜。

Source: “Ch01v2a.pdf” — lecture slides

The cache is a small fast memory between the CPU and main memory.

Cache 是位于 CPU 与主存储器之间的一小块高速存储器。

The processor looks in the cache first: a hit means the data is in the cache and comes fast; a miss means a block is copied from main memory into the cache.

处理器先查 Cache：命中表示数据在 Cache 中，取用很快；未命中则把主存中的一块复制到 Cache。

Average access time = T1 + (1 - H) x T2, where T1 is the cache time, T2 the main memory time and H the hit ratio.

平均访问时间 = T1 + (1 - H) × T2，其中 T1 为 Cache 访问时间，T2 为主存访问时间，H 为命中率。

A high hit ratio makes the average time close to the fast cache time, so the computer is much faster.

命中率越高，平均访问时间就越接近快速 Cache 的时间，计算机也就快得多。

Source: “Ch01v2a.pdf” — lecture slides

Cache size.

Cache 容量。

Block (line) size.

块（行）大小。

Mapping function: direct, fully associative or set associative.

映射函数：直接映射、全相联或组相联。

Replacement algorithm: for example LRU, FIFO, LFU or random.

替换算法：例如 LRU、FIFO、LFU 或随机。

Write policy: write through or write back.

写策略：写直达（write through）或写回（write back）。

Number of cache levels: L1, L2, L3.

Cache 级数：L1、L2、L3。

Source: “Ch01v2a.pdf” — lecture slides

a. Cache size: a bigger cache gives a higher hit ratio, but it costs more and is a little slower.

a. Cache 容量：容量越大命中率越高，但成本更高、速度略慢。

b. Block size: bigger blocks use spatial locality and fetch useful neighbours, but too big a block brings unused data and each miss costs more.

b. 块大小：块大一些能利用空间局部性、把有用的邻居数据一起取来；但块太大会取进无用数据，并且每次未命中的代价更大。

c. Mapping function: direct mapping is simple and cheap but causes conflict misses; fully associative is flexible but expensive and slow to search; set associative is the compromise.

c. 映射函数：直接映射简单便宜但会产生冲突失效；全相联灵活但搜索代价高；组相联是折中方案。

d. Replacement algorithm: LRU gives a good hit ratio but is expensive to implement exactly, so approximations are used; FIFO and random are cheap but give a lower hit ratio.

d. 替换算法：LRU 命中率好但精确实现代价高（通常用近似实现）；FIFO 和随机便宜但命中率较低。

e. Write policy: write through keeps main memory always correct but uses more bus traffic; write back writes fewer times and is faster, but main memory can be out of date.

e. 写策略：写直达能保证主存始终正确，但总线流量大；写回写次数少、更快，但主存内容可能过时。

f. Number of cache levels: more levels improve performance (small fast L1 plus larger L2/L3), but they cost more, use more power and make the design more complex.

f. Cache 级数：级数多性能更好（小快的 L1 配上更大的 L2/L3），但成本、功耗更高，设计也更复杂。

Source: “Ch01v2a.pdf” — lecture slides

LRU stands for Least Recently Used.

LRU 即 Least Recently Used（最近最少使用）。

The idea: replace the block that has not been used for the longest time.

基本思想：替换掉最长时间没有被使用的那一块。

It is a good choice because of temporal locality: data used recently will probably be used again, so the least recently used block is the one least likely to be needed.

它是好选择是因为时间局部性：最近用过的数据很可能再用，所以最久未用的块最不可能被用到。

Source: “Ch01v2a.pdf” — lecture slides

Programmed I/O: the processor does everything and waits, testing the device status again and again for each word; it is simple but wastes processor time.

程序控制 I/O：处理器做所有工作并等待，每传一个字都要反复查询设备状态；简单但浪费处理器时间。

Interrupt-driven I/O: the processor starts the I/O and continues working; the device sends an interrupt when it is ready, so the processor does not wait.

中断驱动 I/O：处理器启动 I/O 后继续工作，设备准备好时发出中断，处理器不必等待。

DMA (direct memory access): a DMA controller moves a whole block between I/O and memory by itself; the processor only sets it up and gets one interrupt at the end.

DMA（直接存储器访问）：由 DMA 控制器自行在 I/O 与存储器之间搬运整块数据，处理器只需设置好，最后收到一次中断。

DMA uses the least processor time, so it is best for large transfers.

DMA 占用的处理器时间最少，最适合大批量数据传输。

Source: “Ch01v2a.pdf” — lecture slides

SMP means symmetric multiprocessing: two or more processors of the same type share main memory and I/O.

SMP 即对称多处理：两个或多个同类型处理器共享主存储器和 I/O。

All processors can run the operating system and applications; no processor is the master.

所有处理器都能运行操作系统和应用程序，没有哪个是主处理器。

Advantages: better performance, higher availability (if one processor fails the system still runs), incremental growth (add processors), and scaling with the same software.

优点：性能更好、可用性更高（一个处理器故障系统仍能运行）、可逐步扩充（增加处理器），并且同一套软件即可扩展。

Source: “Ch01v2a.pdf” — lecture slides

A multicore computer has several processor cores on one chip.

多核计算机在一块芯片上有多个处理器核心。

Each core has its own registers and its own L1 cache; the cores share lower-level caches and main memory.

每个核心有自己的寄存器和 L1 Cache，各核心共享更低层的 Cache 和主存储器。

Several cores do work at the same time, so the computer is faster and uses less power and space than several separate chips.

多个核心同时工作，因此比多块独立芯片更快、更省电、更省空间。
